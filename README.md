Base Layout Template

A responsive base layout template built as a pet project to practice modern frontend development approaches.

Technologies Used
HTML5
SCSS (Sass)
CSS3
Flexbox
CSS Grid
Media Queries
SCSS Mixins
Stylelint
Responsive design for different screen sizes
Semantic HTML structure
Organized SCSS architecture
Automated build process with Gulp
Code quality control using Stylelint
Reusable styles through mixins and variables

DEMO LINK https://github.com/SoraEmpty/LandingPage

Project Goal

The main goal of this project was to improve frontend development skills, learn how to organize styles in large projects, and practice using build tools and code quality standards.
